# Partiture per me

Editor web per canovacci e partiture da live: griglie accordi in notazione italiana, pentagrammi a rigo singolo, sezioni, avvisi, roadmap, trasposizione ed esportazione PDF (A4 e tablet).

- Frontend: Vite + React + TypeScript, VexFlow per il pentagramma, jsPDF + svg2pdf per il PDF vettoriale.
- Salvataggio: Netlify Functions + Netlify Blobs, accesso con password (variabile `APP_PASSWORD`).
- Sviluppo locale: `npm run dev` (senza funzioni i brani restano nel browser).
